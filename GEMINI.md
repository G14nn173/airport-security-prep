# Gemini Project Instructions

Before doing ANY work on this repository:

1. Read `AGENTS.md` completely.
2. Treat `AGENTS.md` as the canonical source of project architecture, constraints, quiz behaviour, PWA rules and branding.
3. Inspect the current implementation before editing.
4. Make only the smallest necessary changes.

MANDATORY:
After EVERY project modification, review and update `AGENTS.md` during the same task.

The user does NOT need to request this explicitly.

A project modification is not complete until `AGENTS.md` has been reviewed and synchronized with the current state.

Do not modify question banks, scoring, timers, answer locking or PWA architecture unless explicitly requested by the user.
